## 过程中发现并处置的问题

| 问题 | 处置 |
| --- | --- |
| salmon 2.7（rust 版）对单端数据默认 FLD = 250±25，EffectiveLength 完全失真 | 改为按实测读长传 `--fldMean 49 --fldSD 3`；残余的 efflen 语义异常经三项独立检验判定不影响相对定量（`docs/decisions/salmon_effective_length.md`） |
| RefSeq `rna_from_genomic` 不含线粒体蛋白编码 mRNA，会使 5.6 的 mtDNA 判定失效 | 改用 `gffread` 从 GFF 抽取宿主转录本（含 19 条线粒体 mRNA） |
| `--no-unal` 导致未比对 reads 丢失，read fate 二级归因无输入 | 改用 `--un-gz` 导出；并加入"局部模式重比对"一级补，使归因成为三级阶梯 |
| 两次 `git add -A` 带入运行中的大文件 | 完善 `.gitignore` + 安装 `.githooks/pre-commit` 体积守门（>5 MB 拒绝，已实际拦截一次） |
