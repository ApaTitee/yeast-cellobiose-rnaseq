## 过程中的问题与处置（供后续阶段参考）

| 问题 | 处置 |
| --- | --- |
| 串行下载约 1 MB/s，预计 2 h 以上 | 改为 3 路并发（`MAXJOBS=3`），聚合 ~8 MB/s |
| 被终止的串行实例遗留 `curl` 子进程，与新实例**并发写同一文件**（会静默损坏数据） | 终止全部相关进程、删除全部部分文件重新下载；脚本加入 **`flock` 互斥锁**杜绝复发 |
| SRR1166443 单连接被限速至 54 KB/s（预计 11 h） | 脚本加入 `--speed-limit 102400 --speed-time 60`，停滞自动断连重试；实测重连后恢复 8 MB/s |
| 陈旧校验记录会混入汇总表 | 每轮开始清理 `checksums/.verify/` |
| `renv::init()` 激活后遮蔽 conda 库，`library(DESeq2)` 直接失败 | 改用 conda 精确锁定，见 `docs/decisions/r_environment.md`；PLAN §1.3/§5.0/§6/附录 B 已同步更新 |
