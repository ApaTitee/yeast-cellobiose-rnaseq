## 排版系统变更（由 Typst 回退到经典 Quarto + LaTeX）

初次交付使用 Quarto 的 Typst 后端，视觉检查发现若干排版缺陷（表内单元格文字重叠、图幅不一致、
参考文献标题重复）。已整体回退到经典 Quarto 排版链路：

| 项 | 变更 |
| --- | --- |
| PDF 引擎 | Typst -> **xelatex**（系统 TeX Live；booktabs/longtable/xeCJK/graphicx 均已就绪） |
| 表格 | 自建 Typst 表格 -> `knitr::kable`（HTML 用 html 格式；PDF 用 latex 格式，booktabs + longtable；列数 >5 时 `\resizebox{\textwidth}` 等比压缩，杜绝溢出与重叠） |
| 图幅 | 逐图设定 `out-width`（68%–100%），两版一致 |
| 参考文献 | 移除手工 References 小节，交由 Quarto 的 `reference-section-title` 生成，消除 "Bibliography" 重复标题 |
| 中文 PDF | xeCJK + 静态 `NotoSansSC-Regular.otf`（xelatex 不支持可变字体；渲染脚本自动复制到 `docs/report/fonts/`，该目录不入库） |
| 产物 | EN 20 页 / ZH 19 页；两版表格数值一致性校验仍为 0 差异 |

保留的 Typst 相关产物仅为 `environment.yml` 中的 `typst` 包（不影响 LaTeX 链路）。
